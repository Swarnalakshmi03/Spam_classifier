Detects whether the given message is spam or not using naive bayes classfier.

In this project, I created a machine learning email classification system to identify spam and non-spam messages. The aim was to improve message filtering systems by detecting and segregating unwanted or potentially malicious content.  The data set contained labeled SMS texts that were labeled as either spam or ham. I carried out detailed text preprocessing, which involved lowercasing, punctuation stripping, stop-word removal, and stemming. All these steps of preprocessing were important to standardize the text data and make it ready for useful analysis.  In feature extraction, Term Frequency-Inverse Document Frequency (TF-IDF) was the technique employed for translating text data to numerical features. TF-IDF served the purpose of focusing more on major words and less on frequently occurring terms, enhancing input quality for the model.  I used a Support Vector Machine (SVM) classifier because it excels at solving binary classification issues. The data was divided into a training subset and a testing subset to determine how well the model generalized. I measured the performance of the classifier through metrics like accuracy, precision, recall, and the confusion matrix, which gave me a detailed insight into its predictive strength.  The last model reached high accuracy and showed good reliability in determining spam messages. This solution finds real-world use in email clients and messaging platforms, providing automatic spam identification and enhanced information security.
